# 人脈廣場｜台灣城市商務人脈媒合

網址:https://ryan81127.github.io/amway-life-game/plaza/

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 廣場本體:台灣城市場景、角色走動與打招呼、輸入需求呼叫廠商、表單 |
| `avatar.js` | 人物形象(性別、髮型、髮色、膚色、上衣、褲子/裙子、6 個預設角色) |
| `data.js` | 設定(`API_URL`、產業顏色、需求關鍵字)與 20 位範例商家 |
| `admin.html` | Demo 後台(只看得到這台瀏覽器送出的測試資料) |
| `admin-ui.js` / `admin.css` | 後台介面,Demo 後台與私人後台共用 |
| `apps-script/Code.gs` | Google Apps Script 後端:資料表、公開 API、私人後台、通知信 |

## 目前是 Demo 模式

`data.js` 的 `API_URL` 是空的,所以:

- 廣場顯示 20 位虛構範例商家
- 送出的表單只存在這台瀏覽器
- 打開 `admin.html`,按「加入範例資料」可以先看後台長什麼樣子

## 連上你的 Google 帳號(約 10 分鐘)

1. 用 **ryan.ttm81127@gmail.com** 登入,開 https://script.google.com ,新增專案,把 `apps-script/Code.gs` 全部貼進去並儲存。
2. 函式選單選 `setup` → 執行 → 授權。會在你的雲端硬碟建立「人脈廣場資料庫(私人)」,裡面有三張表:成員、介紹需求、找廠商需求。
3. 「部署 → 新增部署作業 → 網頁應用程式」,部署兩次:
   - **公開 API**:執行身分「我」,存取權「所有人」。複製網址。
   - **私人後台**:執行身分「存取網頁應用程式的使用者」,存取權「只有我自己」。網址結尾加上 `?admin=1`,這就是你的後台連結(建議存成書籤)。
4. 「專案設定 → 指令碼屬性」新增 `ADMIN_URL`,值填上一步的後台連結,通知信就會附上它。
5. 把公開 API 網址貼到 `data.js` 的 `API_URL`,推上 GitHub。

完成後:

- 加入申請、介紹需求、找廠商需求會寫進你的資料表,並寄信到你的信箱。
- 在私人後台按「核准上架」,一分鐘內就會出現在廣場上。
- 公開 API 只輸出白名單欄位,手機、Email、LINE 不會出現在網站或原始碼裡。
- 私人後台每次操作都會檢查登入的是不是你的帳號。

## 後台功能

- **加入申請**:看完整資料、私人聯絡方式、人物形象,一鍵核准或不通過
- **介紹需求**:誰想認識誰、原因、聯絡方式;狀態可選 新需求 → 已聯絡 → 已介紹 → 洽談中 → 成交
- **找廠商需求**:訪客找不到的廠商;可複製一段邀請訊息傳給你找到的廠商
- **缺口雷達**:統計廣場上還沒有、但有人在找的產業
- **已上架**:可隨時下架
- 每筆都能寫備註
