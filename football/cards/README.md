# 足球看板知識卡

每支球隊一個檔案（`teams/<ESPN 球隊 ID>-<名稱>.json`），每個球場一個檔案（`venues/`），在 `index.json` 登記後，看板遇到這支球隊或球場就會自動載入。同一支球隊下次再出賽，只要更新球員、教練與近期事件，不用重查全部。

## 每場準備目標
- 5 個球隊故事（topic：球隊）
- 5 個球員故事（topic：球員）
- 5 個城市／國家冷知識（topic：城市、國家、文化、趣聞）
- 10 句觀眾互動話術（卡片的 ask，不足時看板自動補齊）

## 卡片欄位
| 欄位 | 說明 |
|---|---|
| id | 唯一代號 |
| topic | 球隊／球員／城市／國家／文化／趣聞 |
| title | 標題 |
| fact | 事實內容，50–100 字 |
| sources | 來源陣列：`{ "name": "...", "url": "..." }` |
| checked | 查證日期 `YYYY-MM-DD` |
| say | 口語版，可直接念 20–40 秒 |
| humor | `{ "light": "輕鬆版", "spicy": "嗆辣版" }` |
| ask | 引導觀眾留言的一句提問 |
| when | 使用時機：開場、暫停、中場、冷場、賽後 |
| status | 已查證／需更新／不可當成事實播報 |
| note | 補充說明（例如：是否入選本次名單未確認） |
| player | 球員卡的英文原名（選填） |

兩隊之間專屬的故事放在 `rivals.<對手 ESPN ID>`。

## 自動過期
`index.json` 的 `ttlDays` 設定各主題的有效天數（球員 60 天、球隊 180 天、文化／城市／國家 730 天）。超過期限的「已查證」卡，看板會自動改標「需更新」。
